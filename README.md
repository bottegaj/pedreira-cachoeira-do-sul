# Pedreira Cachoeira do Sul

Site institucional estático da Pedreira Cachoeira do Sul.

## Arquivos principais

- `index.html`: textos e estrutura do site.
- `styles.css`: aparência visual.
- `script.js`: menu e botão de orçamento pelo WhatsApp.
- `assets/images`: logotipos e fotografias.
- `assets/videos`: vídeos da operação.

## Atualizações simples

1. Para trocar uma foto, substitua o arquivo dentro de `assets/images` mantendo o mesmo nome.
2. Para trocar textos, edite o arquivo `index.html`.
3. Para alterar o WhatsApp, edite o número em `script.js`.
4. A Vercel republicará o site automaticamente após cada alteração confirmada no GitHub.

## Imagem principal

Adicione uma foto chamada:

`assets/images/banner-principal.jpg`

Recomendação: imagem horizontal, proporção 16:9, largura mínima de 1.920 pixels.
